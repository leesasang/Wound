# Wound Analyzer

Streamlit + OpenCV 기반 상처 **후보** 영역 분석·변화 추적 프로그램.
제공된 「Wound Analyzer 개발 보고서」의 PyQt 기능을 웹으로 재구현한 교육·발표용 프로젝트입니다. 원본 코드와 정확한 임계값이 없어 알고리즘 수치와 화면은 새로 작성했으며, PDF의 실험 결과를 재현했다고 주장하지 않습니다.

## 실행

Python 3.11 권장.

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud 배포

저장소 `leesasang/Wound`, 브랜치 `main`, 메인 파일 `app.py`를 선택합니다. Python 3.11을 사용합니다. API 키나 별도 DB는 필요하지 않습니다.

## 기능

- PNG/JPEG/WebP 업로드, EXIF 회전 보정, 최대 변 1,200px로 축소
- 현재·이전 사진 각각 ROI 범위 조정: 웹 버전은 가로/세로 슬라이더 사용
- HSV 민감도, 최소 후보 면적, Morphology 커널 조정
- 가장 큰 후보의 면적·둘레·사진 내 비율·원형도, 색상 비율과 Hue 히스토그램
- 입력/Mask/잡음 제거/Contour 중간 처리 결과
- 이전 사진과 픽셀 면적 변화 비교, 세션 내 기록과 그래프
- 결과 PNG, 색상 대시보드 PNG, 면적 추이 PNG, CSV, 이미지 포함 HTML 보고서
- 재현 가능한 합성 샘플 6종 (실제 환자 사진 아님)

## 알고리즘 및 단위

`wound_processing.py`는 RGB를 OpenCV HSV로 바꿉니다. 민감도 s(0~100)에 따라 빨간 Hue의 양 끝 범위는 `round(3+0.12*s)`, 최소 채도는 `round(110-0.8*s)`, 최소 밝기는 20입니다. Opening 이후 Closing을 수행하고 최소 면적 이상인 가장 큰 외곽선을 선택합니다.

면적은 `cv2.contourArea`, 둘레는 `cv2.arcLength`입니다. 외곽선 내부 구멍은 포함됩니다. ROI 내부 좌표를 원본 처리 영상에 다시 배치하며, 면적과 둘레는 **축소 후 처리 영상의 px² / px**입니다. cm²가 아닙니다. 색상 통계의 분모는 ROI 또는 채운 후보 마스크의 픽셀 수이므로 contour 면적과 다릅니다.

색상 대시보드는 서로 겹치지 않는 그룹을 사용합니다: 어두운색 V<60, 붉은색 (H≤10 또는 H≥170) 및 S≥60 및 V≥60, 나머지는 기타. 이는 검출 민감도와 별개의 고정된 기술 통계이며 조직 진단이 아닙니다.

변화율 = `(현재 면적 - 이전 면적) / 이전 면적 × 100`. 음수는 픽셀 면적 감소입니다. 한쪽이 미검출이면 계산하지 않습니다. 촬영 거리·해상도·각도·조명 변화는 결과를 바꾸며, 같은 처리 해상도도 같은 물리적 배율을 보장하지 않습니다. 회복률로 해석하면 안 됩니다.

PDF의 '자동 검출 믿음도'는 임상적 확률로 오해될 수 있어 복제하지 않았습니다. 대신 경계 접촉·다중 후보 경고와 원형도를 제공합니다. 기준 마커·실제 단위 환산·딥러닝·임상적 정확도 검증은 구현 범위 밖입니다.

## 파일 구조

- `app.py`: Streamlit UI와 세션 기록
- `wound_processing.py`: 입력 검증, HSV 처리, 특징 계산, 합성 샘플
- `exports.py`: PNG·HTML·그래프 내보내기
- `tests/test_processing.py`: 기하 계산, ROI, 미검출, 입력 및 HTML 안전성 검증
- `.streamlit/config.toml`: 화면 테마와 업로드 한도

## 발표 시연 (약 2분)

1. 현재 샘플 분석 → 후보 면적·중간 처리 확인.
2. 이전 사진 비교 켜기 → 면적 감소 확인 (회복률 아님).
3. 배경 오검출 샘플 분석 → 큰 배경 물체가 선택되는 한계 확인.
4. ROI를 가로 30~75%, 세로 20~80%로 제한 → 후보 재분석.
5. 기록 추가 및 CSV·HTML 다운로드.

## 데이터와 검증

업로드 사진은 Streamlit 서버 메모리에서 처리되며 앱 코드에서 디스크나 외부 API로 저장·전송하지 않습니다. 기록은 브라우저의 연결 세션 메모리에만 존재하며 재접속·서버 재시작 시 사라질 수 있습니다. 공용 배포에는 식별 가능한 환자 사진을 사용하지 마세요.

```bash
pip install pytest
python -m pytest -q
```

합성 이미지 테스트는 구현 동작 확인일 뿐 임상적 분할 정확도 평가가 아닙니다.
